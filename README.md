# Projeto1_ALG2026_GDP

## Bichinho Virtual - Tamagotchi

### O Tamagotchi foi uma febre na década de 90, pois ter um pet virtual era uma grande inovação. A ideia deste projeto é criar o seu próprio Tamagotchi usando uma linguagem de programação básica, o Portugol, e muito raciocínio lógico. Ele não precisa de frames nem de interface gráfica: é um programa de nível básico, que roda direto no terminal.
